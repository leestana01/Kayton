# 🎩 케이튼 교수와 사라진 소스코드

> _"신사에게 풀지 못할 퍼즐은 없는 법이란다."_ — 케이튼 교수

레이튼 교수 스타일의 **코딩 퍼즐 어드벤처 게임**입니다.
전설의 발명가 비트 경이 남긴 저택에서, 케이튼 교수와 조수 루카가 되어
수수께끼의 인물 **닥터 널**보다 먼저 〈전설의 소스코드〉를 찾아내세요.

## ✨ 특징

- **3개 챕터, 12개의 코딩 퍼즐** — 이진수, 반복문, 논리 회로, 카이사르 암호, 버블 정렬, 재귀(피보나치), 모듈로 연산, 스택, 디버깅, XOR, 이진 탐색, ASCII 해독
- **피카랫 시스템** — 총 524 피카랫. 오답을 낼수록 획득량이 줄어듭니다 (최저 50%)
- **힌트 코인** — 탐색 장면에서 숨은 코인을 찾아 퍼즐당 3단계 힌트를 열 수 있습니다
- **자동 저장** — `localStorage` 기반, 브라우저를 닫아도 이어서 플레이
- **엔딩 칭호** — 최종 피카랫에 따라 4단계 칭호 부여
- **모바일 웹 완전 대응** — 터치 UI, `100dvh` 레이아웃, 세이프 에어리어(노치) 대응, 반응형
- **백엔드 없음** — 순수 HTML/CSS/JS. 빌드 도구도, 외부 라이브러리도, 서버도 없습니다

## 🕹️ 플레이 방법

배포된 GitHub Pages 주소로 접속하면 바로 플레이할 수 있습니다.
로컬에서는 `index.html`을 브라우저로 열기만 하면 됩니다.

```bash
# 로컬 서버로 띄우고 싶다면 (선택)
python3 -m http.server 8000
# → http://localhost:8000
```

## 🚀 배포 (GitHub Pages)

`.github/workflows/deploy.yml` 워크플로가 푸시 시 자동으로 GitHub Pages에 배포합니다.

처음 한 번만 저장소 설정을 확인하세요:

1. **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정
   (워크플로가 자동으로 활성화를 시도하지만, 조직 정책에 따라 수동 설정이 필요할 수 있습니다)
2. 브랜치에 푸시하면 Actions 탭에서 배포가 실행되고, 완료 후
   `https://<사용자명>.github.io/<저장소명>/` 에서 게임이 열립니다.

```

js/game.js          # 게임 엔진 (진행/저장/퍼즐 판정/효과음/HUD)
```
